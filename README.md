# THE HUNT

Open index.html to test locally, or upload the contents of this ZIP to the root of your GitHub Pages repository.

Edit questions and upload audio at admin.html. After editing, download a new website package and upload its contents to GitHub.

Audio filenames are question-N-10s.mp3, question-N-15s.mp3 and question-N-20s.mp3. The host editor can accept other audio file types too; the selected file is saved using the expected filename.
